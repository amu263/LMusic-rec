# LMusic 0.2.0

**把本地音乐，听回它本来的样子。**

V0.2 带来全新的 USB 独占控制中心：从设备接管、音量安全、缓冲策略到信号监测，所有关键状态都能看见、能调整。

## 本次更新

### 全新 USB 独占控制中心

- 设备状态卡：DAC 名称、USB ID、输出链路、采样率与位深一屏掌握；
- 传输状态：实时缓冲水位、ISO 传输、欠载与错误计数；
- 信号路径：源文件 → 播放流 → DAC 端点，完整展示音频去向；
- 支持深色模式与统一的大圆角卡片设计。

### 安全音量与平滑控制

- 首次接管 DAC 时从设备安全低音量开始，避免突然满音量爆音；
- 默认 12% 低音量起步，支持 DAC 硬件音量与数字音量两种控制；
- 音量平滑交接，切换控制方式时保持响度连续；
- USB 音量独立于系统音量，不随通知/通话音量跳变。

### 更完整的 USB 音频能力

- 输出采样率：自适应或 44.1–192 kHz 固定输出；
- 输出位深：自适应 / 16-bit / 24-bit；
- 前台 / 后台独立缓冲设置，兼顾稳定性与切歌响应；
- 位深、声道兼容回退；
- 延迟建立 USB 输出链路，兼容带屏 DAC；
- 未打开 App 时的 USB 授权入口；
- 数字余量、TPDF 抖动、峰值/削波/异常采样监测；
- 音量、格式、缓冲与兼容性设置即时联动。

### 设置体验统一

- 全部设置页采用新的卡片式排版与统一的开关、滑杆、下拉选择；
- 更清晰的层级、留白与触控区域；
- 保留原有功能与交互习惯。

## 安装

1. 下载 `LMusic-0.2.0.apk`；
2. 允许安装未知来源应用；
3. 安装后授予本地音频读取权限。

- **系统**：Android 5.0（API 21）及以上
- **架构**：arm64-v8a / armeabi-v7a / x86_64
- **USB 独占原生驱动**：arm64-v8a

> 本版本使用独立发布签名。若安装过其他签名的版本，请先卸载。
